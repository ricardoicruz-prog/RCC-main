# RCC Custom Skills

Brand-building skill collection for Ricardo Cruz Consulting (RCC).

## Brand Building Skills

29 skills covering brand strategy, naming, identity, voice, positioning,
messaging, auditing, guidelines, launch, and marketing channels. `brand-context`
is the foundation skill — every other brand skill reads it first, so run it once
per client to capture identity, audience, and positioning.

Source: https://github.com/arnabbagxd/Brand-building-skills (MIT License — see `LICENSE`).

These skills load automatically when the task matches a skill's description; no
manual setup is required beyond having this directory in the project.
